# 文档区入口：不要从文件列表开始读

> 更新日期：2026-09-02
>
> TraceId：`7e282555-47f3-432d-a123-7ff8d5477154`

这里保留了学校专题、四年录取数据、复试、培养合同、全国普查和证据规则，所以文件很多；它们是证据附件，不是阅读顺序。

## 你只需要两个入口

1. **[当前结论总览](start-here-current-conclusions.md)**：人物画像、当前梯子、新扩展、关键分数、现实风险和下一步行动都在这一份里。
2. **[完整报告索引](research-report-index.md)**：需要查某所学校、某项分数、复试或培养合同时，按分类找到专题报告。

不要根据文件名的新旧自行拼结论。历史报告可能保留旧年度科目、复试人口、二手线索或后来已纠正的数据；当前结论以总览为入口，以专题报告中的证据等级为边界。

如果你不知道该打开哪份文件，直接回到[当前结论总览](start-here-current-conclusions.md)，或者用自然语言问：“我要比较哪两所学校，应当看哪些材料？”
