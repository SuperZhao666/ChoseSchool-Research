## 你的固定边界

### 接受

- 软件工程、计算机技术、计算机科学，以及与软件开发直接相关的人工智能；
- 算法、数据结构、数据库、操作系统、离散数学、编译原理；

### 排除

- `085412 网络与信息安全`、`145200 密码`；
- 渗透、漏洞利用、逆向、ROP、靶场、Web 攻防、网络监听等攻防实践；

- 把复试线、历史最低分、专项低分或单个上岸案例包装成安全线。

普通编程机试不是你要排除的“攻防上机”。C/C++、数据库、算法和数据结构都属于你的软件工程专业范围。

## 怎样理解项目里的分数

项目中常见的数字不是同一种东西：

| 数字 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 复试线 | 进入复试的最低门槛 | 最终录取中心、安全线、普通名额 |
| 复试名单分布 | 入围人群大致强度 | 实际录取者分布 |
| 最终名单中位数 | 当年、该项目、该人口的中心 | 下一年必然分数线或你的录取概率 |
| 最低录取分 | 存在一个尾部个案 | 低分普遍可复制或“捡漏” |
| 目录计划 | 招生阶段的计划原值 | 最终普通统考人数 |
| 同源学校个案 | 某类本科背景存在上岸可能 | 该项目对普通本科友好或通过率高 |

只有同一项目、同一年度、同一学习方式、同一科目合同下的最终普通人口才适合直接比较。专项、推免、联培、调剂、复试人口和不同专业课年度不能混用。

## 分数出来后怎样缩小范围

至少完成 5 套严格 `101+204+302+408` 全真模考，再用最近 3 套中位数和单科波动做第一次收敛：

| 稳定模考窗口 | 重点核验 | 不要做的事 |
|---|---|---|
| `≥385` | 山大、厦大、重大计算机；北交、郑大作为相对低压替代 | 因总分高就忽略机试硬线、联培和实践 |
| `370—384` | 厦大／重大升级；北交／郑大主研究；西南交大比较 | 把单年中位数当固定门槛 |
| `355—369` | 北交、郑大为核心；西南交大、辽大作中间层 | 把复试线叫安全线，或把合工大、苏大叫保底 |
| `340—354` | 西南交大、辽大；接受地域时看新疆大学 | 为了学校名气继续维持不现实的 985 主线 |

2. **当年普通名额**：推免、专项、联培、卓工、异地培养和调剂经常混在不同阶段，不能简单相减。
3. **你的真实分数窗口**：当前没有五套严格全真模考，因此不能给个人录取概率。
4. **你的机试稳定性**：还需要三种实测——120 分钟只用 C、150 分钟 OJ＋数据库／软件工程、180 分钟 C/C++ 五题。
5. **培养与毕业合同**：导师分配、实践时长、企业驻场、成果门槛、校区和住宿是很多项目的真正风险。
6. **普通本科公平性**：多数最终名单不披露本科院校，因此没有足够数据计算临沂大学或普通双非录取率。

## 你现在最值得做的三件事

1. 完成五套四科全真模考，记录总分、每科分数和波动，不只报一个最好成绩；
2. 完成三种限时编程实测，记录完成题数、首次通过时间、调试次数和环境损耗；
3. 明确四个现实选择：能否接受北京无宿舍、能否接受乌鲁木齐／沈阳／佛山等地点、家庭可承受的三年总成本、能否接受半年到一年企业实践。

有了这些输入，项目才能从“调研学校”转向“为你做最终报名决策”。

## 阅读顺序

如果只有 5 分钟，就读本页到“当前真正值得看的梯子”为止。

需要进一步判断时，按这个顺序：

1. [当前候选决策矩阵](current-candidate-decision-matrix-2026-08-24.md)：看完整 16 项及扩展池；
2. [四年录取数据审计](current-16-four-year-admission-data-audit-2026-08-31.md)：看每年实际人口和总分；
3. [最终录取者分科成绩审计](current-16-four-year-admitted-subject-score-distribution-audit-2026-08-31.md)：看政治、英语、数学和专业课结构；
4. [成本、实践和毕业负担总表](current-16-post-admission-cost-practice-and-graduation-burden-matrix-2026-08-30.md)：看考上以后要承担什么；
5. [真实复试与调剂风险](current-candidates-real-retest-experience-and-adjustment-risk-2026-08-27.md)：看复试现场、材料暴露和调剂时间；
6. [2027 正式目录门禁](current-16-2027-exact-catalog-gate-refresh-2026-08-30.md)：看哪些事实仍未发布；
7. [全部报告索引](research-report-index.md)：只有找某所学校或某类证据时再打开。

本地还有一份不会上传 GitHub 的 `personal-selection-current-conclusion.md`，用于记录家庭预算、地域接受度等私人结论。公开总览只保留不会暴露个人敏感信息的画像边界。
