现在还不能诚实地锁定一所学校，也没有证据支持“稳校、保底或个人录取概率”。当前最值得投入时间的是：

- **主研究**：北京交通大学 `010-085405`、郑州大学 `084-085410`；
- **中间层比较**：西南交通大学 `048-085410`、辽宁大学 `085405`；
- **接受地域才启用**：新疆大学 `085405`；
- **高分后升级**：厦门大学 `085404`、重庆大学计算机学院 `085404`、山东大学 `085404`；
- **最值得继续观察的新扩展**：上海大学 `008-085405`、武汉理工大学 `010-085405`、华南师范大学 `041-085405`、长安大学 `006-085405/085404`；湖南大学 `085400` 只作为 2027 高压目录观察项。

## 怎样理解项目里的分数

项目中常见的数字不是同一种东西：

| 数字 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 复试线 | 进入复试的最低门槛 | 最终录取中心、安全线、普通名额 |
| 复试名单分布 | 入围人群大致强度 | 实际录取者分布 |
| 最终名单中位数 | 当年、该项目、该人口的中心 | 下一年必然分数线或你的录取概率 |
| 最低录取分 | 存在一个尾部个案 | 低分普遍可复制或“捡漏” |
| 目录计划 | 招生阶段的计划原值 | 最终普通统考人数 |
| 同源学校个案 | 某类本科背景存在上岸可能 | 该项目对普通本科友好或通过率高 |

只有同一项目、同一年度、同一学习方式、同一科目合同下的最终普通人口才适合直接比较。专项、推免、联培、调剂、复试人口和不同专业课年度不能混用。

## 现在仍然缺少的决定性信息

1. **2027 正式目录**：2026-09-02 已对当前 16 项完成同日全池复核，仍为 `0/16`；扩展池的上大、武汉理工、华南师大另算为 `0/3`。后续必须取得同一项目、同一招生年度的 2027 正式四码原行，才能升级状态。
2. **当年普通名额**：推免、专项、联培、卓工、异地培养和调剂经常混在不同阶段，不能简单相减。
3. **你的真实分数窗口**：当前没有五套严格全真模考，因此不能给个人录取概率。
4. **你的机试稳定性**：还需要三种实测——120 分钟只用 C、150 分钟 OJ＋数据库／软件工程、180 分钟 C/C++ 五题。
5. **培养与毕业合同**：导师分配、实践时长、企业驻场、成果门槛、校区和住宿是很多项目的真正风险。
6. **普通本科公平性**：多数最终名单不披露本科院校，因此没有足够数据计算临沂大学或普通双非录取率。

## 你现在最值得做的三件事

1. 完成五套四科全真模考，记录总分、每科分数和波动，不只报一个最好成绩；
2. 完成三种限时编程实测，记录完成题数、首次通过时间、调试次数和环境损耗；
3. 明确四个现实选择：能否接受北京无宿舍、能否接受乌鲁木齐／沈阳／佛山等地点、家庭可承受的三年总成本、能否接受半年到一年企业实践。

有了这些输入，项目才能从“调研学校”转向“为你做最终报名决策”。
