# 按个人画像收敛择校：测量协议与决策更新规则（2026-08-18）

## 这份文件解决什么问题

目前已经能确认你有持续的程序设计、算法和限时竞赛经历，但还不能把证书直接换算成复试分或录取概率。真正缺的不是“再找一个奖项”，而是把已有能力迁移到考研场景时的表现测出来：

- 四科初试能否在同一套卷、同一规则下稳定完成；
- 120—180 分钟的陌生机试中，能否独立读题、编码、编译、调试和提交；
- 面对数据结构、数据库、复杂度和项目经历追问时，能否清楚解释；
- 你的优势是否能抵消高机试项目的现场波动，还是只在熟悉题型中有效。

因此本文件不输出学校概率，也不把自测结果冒充官方事实；它规定下一批数据应该怎样记录，以及数据进入后模型怎样变化。

## 当前画像基线

以下是已经进入证据账本或偏好账本的内容：

| 维度 | 当前状态 | 模型含义 |
|---|---|---|
| 竞赛/能力成果 | 9 条，13 份证据文件支持；PAT 奖状和成绩证书已合并为一次成果 | 支持“程序设计准备资产真实存在” |
| 奖学金 | 3 条 | 支持持续学习记录，不直接替代专业能力 |
| 偏好问卷 | 23/23 已答，985 优先、211 对冲，排除兰州大学 | 作为排序和硬排除输入，不是学校客观标签 |
| 2027 目标绑定 | 13 条全部是 `research_hypothesis`，正式目标观测为 0 | 目前不能给冲/稳/保/概率 |
| 严格四科模考 | 0/5 | 初试压力位置不可计算 |
| 机试测量 | 0 条 | 奖项到现场机试的迁移能力未知 |
| 公平性审查 | 0 条 | 不能用“普通本科友好/歧视”传闻修正排序 |

## 当前备考状态中的真正短板

模型还保存了几条来自你本人当时的学习进度自述。它们不是能力测量，也不是永久人格标签，但在第一次严格模考前，确实是比“学校历史最低分”更有决策价值的风险提示：

| 科目/行为 | 当前可核实状态 | 对择校模型的影响 |
|---|---|---|
| 101 政治 | 尚未开始 | 不能用总分想象替代；优先建立第一条单科基线 |
| 204 英语二 | 黄皮书精读约半套多，一套完整卷尚未完成 | 进度不等于分数，先做完整计时单科卷 |
| 302 数学二高数 | 基础内容进行中，严格分数未知 | 高数覆盖不等于稳定得分，必须测卷 |
| 302 数学二线性代数 | 已买书但尚未开始 | 当前是明确的知识覆盖缺口，不能被竞赛成绩抵消 |
| 408 | 没有严格单科/整套成绩 | 算法竞赛经历不能代替 408 四科训练证据 |
| 作息和执行 | 自述为“边玩边学”、效率偏低、约 12 点起床 | 只作为计划执行风险，不升级为能力结论 |

因此，当前最有价值的第一批数据不是继续收集奖项，而是让 101、204、302（尤其线代）和 408 各自出现一条可复核的严格单科记录。没有这一步，任何学校分层都很容易把“准备方向匹配”误读成“本人分数适配”。

## 你的优势和风险要分开

### 已经有证据支持的部分

你不是从零开始学编程：百度之星、GPLT、码蹄杯、传智杯和 PAT 证书共同支持你有竞赛环境、限时解题和程序设计训练经历。个人奖、团队奖和省级团队奖已经分开记录；团队奖不会被错误解释成完全独立的个人排名。

### 仍然未知的部分

证书不能回答下面这些复试问题：

1. 换成陌生题面后，独立解题率是否仍稳定；
2. 代码第一次提交失败后，能否快速定位边界和编译问题；
3. 120、150、180 分钟三种时限下，表现是否明显下降；
4. C/C++、数据结构、数据库和复杂度解释是否达到目标学院要求；
5. 面试压力下，能否把奖项、具体题目和自己的贡献讲清楚。

所以当前判断是“机试项目条件性匹配”，不是“竞赛奖项带来录取加成”。高机试权重既可能放大优势，也可能放大现场失误。

## 分三层采集个人数据

### 第一层：严格四科窗口（先于学校比较）

完成 5 套同一协议的 `101+204+302+408` 完整模考。每套必须记录：

- 日期、试卷标识和是否第一次作答；
- 政治、英语二、数学二、408 四科分数或区间；
- 是否完整计时、是否查资料、是否接受帮助、是否中途暂停；
- 每科的失分原因和下次行动。

命令接口已经存在，示例（数值仅示例，不要照抄）：

```powershell
python manage.py mock-add --date 2026-08-20 --paper "paper-01" `
  --politics 62 --english 68 --math 88 --cs408 96 `
  --strict-timed --note "首次完整作答，记录数学线代失分"
```

模型使用最近 5 套同协议有效记录：保守值取总分下界序列的第二低值，常态值取第三低值。没有 5 套时，不能进入个人压力角色。

### 第二层：机试迁移测量（初试主线稳定后）

至少 3 次，分别模拟 120、150、180 分钟；尽量使用 C/C++、陌生题、无资料、无帮助、不可暂停计时。每次记录：

- 题目总数和独立解决题数；
- 首次解出耗时；
- 调试耗时；
- 编译错误、超时、边界错误和主要卡点；
- 是否第一次接触、是否看过题解、是否得到协助；
- 题目来源、难度和评分方式。

命令接口示例：

```powershell
python manage.py machine-add --date 2026-09-01 --duration 120 `
  --language cpp --environment "local-g++" --source "unknown-mixed-set-01" `
  --difficulty mixed --total 5 --solved 3 `
  --first-solve-minutes 24 --debugging-minutes 31 `
  --scoring-method solved_count --first-exposure --strict-timed `
  --note "第一次120分钟陌生题机试"
```

这类记录是 `machine_preparation_measurement`，不是正式成绩。只有目标项目 2027 复试合同出现后，才能判断语言、时长、题型和硬线是否真正可比。

### 第三层：综合复试表达

至少做 2 次完整模拟，固定包含：

- 一道数据结构/算法题的口述思路和复杂度；
- 一道数据库或软件工程基础题；
- 一个竞赛项目的“我做了什么、难点是什么、如何验证”的三分钟说明；
- 对团队奖和个人奖分别说明个人贡献，不能混为一谈；
- 一次被追问或被指出错误后的修正。

这部分先保留为复盘材料，不把面试自评分写成数据库事实。等目标学院正式复试合同出现后，再绑定具体测量维度。

## 数据进入模型后的更新顺序

模型不做加权总分，也不把学校层级抵消证据缺口，固定按以下顺序更新：

1. **硬排除**：兰州大学等明确拒绝项直接排除；专业代码、培养方式、地点或初试四科不符合用户硬条件时排除。
2. **目标年门禁**：只有同一项目、同一年、正式目录明确 `101+204+302+408`，候选才从研究假设进入正式目标观测。
3. **普通名额和复试合同**：普通统考、推免、少干、士兵、联培、非全必须分开；计划减推免不自动等于普通名额。
4. **个人初试窗口**：五套严格模考完成后，才计算个人保守值和单科风险；不完整就保持 `research_only`。
5. **机试条件性匹配**：机试测量协议与目标复试的语言、时长、评分方式相近，且数据足够时，才把高机试项目标为“可测量匹配”；仍不输出概率。
6. **历史压力**：历史数据只用同项目、同四科、同培养口径且有可复核统计元数据的年度；单年只能叫 `single_year_observation`，不能叫安全线。
7. **公平性**：没有项目年度、普通本科背景口径的官方证据时，不允许用学校声誉或传言排序。

## 你会得到什么样的结果

### 如果初试窗口尚未完成

输出：候选池和资料缺口，全部 `research_only`；高机试项目只显示“条件性适配”，不显示冲/稳/保。

### 如果初试窗口完成、但目标目录未发布

输出：个人压力位置已测出，但 2027 目标仍未绑定；继续追踪目录，历史数据仍不进入 2027 录取判断。

### 如果目录、普通名额、复试、公平性和初试窗口都完成

输出：按证据完整度、历史压力、985/211 偏好、专业匹配、复试负担和容量风险的词典序排列；仍不计算“上岸概率”。

### 如果机试表现不稳定

不会简单把所有高机试项目删掉，而是把它们标为“高匹配、高波动”，同时增加更依赖初试或综合面试的比较项目。这样符合你的真实画像：算法经历是资产，但现场迁移能力需要实测。

## 当前最值得投入的顺序

1. 初试主线：先让 101、204、302（含线代）和 408 各有一条严格单科基线，再完成第一套严格四科小测，最后滚动到 5 套窗口；数学二线代和政治是当前不能被竞赛优势掩盖的变量。
2. 低成本机试维护：初试前保持每周一次短时 C/C++、数据结构或数据库练习，不把大量时间从初试主线抽走。
3. 目录跟踪：西南交通大学动态目录入口已经出现但目标学院查询为空；华东师大官方预告把正式目录时间指向 9 月底至 10 月初；其余候选仍按待发布处理。
4. 目录发布后的第一批核验：先核四科和培养方式，再核普通名额与专项拆分，最后才看历史分数和个人适配。

## 当前结论

你的画像最适合“初试稳定性为底座，程序设计能力作为可测量复试增益，985 主研究与 211 对冲并行”的策略。当前最重要的不是继续堆叠奖项，而是完成第一套严格四科记录和第一条合规机试测量；这两条数据会比再增加一条奖项更能改变择校排序。

本文件不新增学校事实、不改变已有裁决，也不把自测结果升级为官方证据。
