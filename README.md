# ChoseSchool：2027 软件工程方向择校信息库

这是一个择校信息调研项目。它服务于软件工程本科生的 `101+204+302+408` 考研决策，把招生目录、科目调整公告、复试办法、录取名单、个人偏好和研究假设分开保存，避免把图片里的推荐分数、宣传规模或历史最低分误包装成 2027 录取概率。

## 先看人类可读结果

- [当前择校清单](docs/personal-selection-current-conclusion.md)：当前真正会看的 16 个软件工程／计算机／人工智能项目，以及明确的专业边界和待补证据。这是日常阅读入口。
- [重点 211 后续备选官方核验](docs/priority-211-backup-official-audit-2026-08-22.md)：逐校核实北交、西电、合工大、苏大、郑大、西南交大和南昌大学；西电因 `101+201+301+408` 与本人严格 22408 冲突而不纳入，其余合适项目进入待核研究池。
- [全国 211 近三年证据链（第一批）](docs/nationwide-211-three-year-evidence-batch-2026-08-22.md)：把辽宁大学、郑州大学和新疆大学的 2024—2026 目录、计划、复试和拟录取口径逐年拆开；重点揭示新疆大学 2024 为 `839` 而非 408，以及郑州大学综合排序表不能当最终录取名单。
- [全国 211 近三年证据链（第二批）](docs/nationwide-211-three-year-evidence-batch-2-2026-08-22.md)：核验北交、合工大和苏大；确认北交、合工大都只有 2026 与本人严格 22408 同合同，苏大连续三年线索仍因 2024/2025 正式目录原件缺口保持待核。
- [软件工程范围内的 2026 历史压力快照](docs/pressure-landscape-snapshot-2026-08-18.md)：只比较与本人专业方向相符、且口径相对清晰的历史项目；不把单年最低分当作“稳”或录取概率。

当前候选只接受软件工程、计算机技术、计算机科学及与软件开发直接相关的人工智能方向。算法、数据结构、数据库、OJ 和 C/C++/Java/Python 普通编程考核属于专业内考核；`085412`、`145200`、网安学院、密码方向以及漏洞利用、渗透、逆向、靶场等攻防实践不进入当前候选或压力比较。

## 当前研究原则

1. 图片是检索线索，不是录取证据。
2. `planned`、`received`、`actual` 三个推免阶段不互相替代；“总计划减推免”不自动等于普通统考名额。
3. 推荐分数、平均分、宣传规模和单年最低分不直接生成冲稳保或概率。
4. 目标年正式目录、普通名额、复试合同、公平性审查和个人测量窗口任一缺失，都保持 `research_only`。
5. 原始来源、事实主张、裁决、复核和审计均采用追加式记录；历史结论被纠正时追加影子值，不覆盖原行。

当前画像下的候选研究池可以用只读命令查看：

```powershell
$env:PYTHONIOENCODING='utf-8'
python manage.py candidate-report
python manage.py --json candidate-report --candidate-target-id 10
python manage.py candidate-report --history --details
```

`candidate-report` 只组合候选身份、用户策略分组、画像适配缺口、历史可比性审查和个人测量/成果资产摘要，不写数据库。每条候选都明确带有 `selection_output.scope=research_only` 与 `probability_status=not_estimated`；`985_priority_research`、`211_hedge_research` 和 `non_211_comparator_research` 是用户指定的取证顺序，不是学校客观层级、冲稳保角色或录取概率。默认输出摘要；只有显式 `--details` 才展开规范化 JSON、事件 ID和证据哈希。

## 信息库与核验工具（辅助，不是项目目的）

- `docs/`：公开的人类可读结论、研究方法、证据边界和官方来源链接。
- `data/`：本地追加式研究账本；原始来源与后续清洗、核验、裁决分开保存。
- `src/`、`manage.py`、`tests/`：帮助防止误改原始来源、混淆计划口径或把历史数据冒充目标年结论的核验工具，不是择校项目的最终产出。
- `config/settings.example.toml`：不含个人值的配置模板；真实 `config/settings.toml` 只保留在本地。

## 本地数据边界

公开版故意不包含：

- `data/*.sqlite3`、`data/*.db`：本地申请人数据库，可能包含个人偏好、成果和审计记录；
- `outputs/*.(xlsx|xls|csv)`：从本地库导出的工作簿；
- `待调查信息/`：原始聊天图片；
- 个人成果证书、云盘链接、个人测量日历和个人择校草稿。

这些文件仍可在本地工作区使用，并已加入 `.gitignore`；它们不会因为本次公开推送而上传。

首次使用时，请复制 `config/settings.example.toml` 为本地 `config/settings.toml`，再填写自己的画像字段。
